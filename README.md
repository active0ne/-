# 家族カレンダー 👨‍👩‍👧‍👦

家族みんなの予定を簡単に管理できるWebアプリケーションです。

## 🌟 特徴

- 📅 **月間カレンダー表示** - 見やすい月間カレンダーで予定を一覧
- 👨‍👩‍👧‍👦 **家族メンバー管理** - メンバーごとに色分けして予定を表示
- ➕ **簡単な予定追加** - クリックで簡単に予定を追加・編集・削除
- 💾 **自動保存** - ローカルストレージで自動的にデータを保存
- 📱 **レスポンシブデザイン** - スマートフォンでも快適に利用可能
- 🇯🇵 **日本語対応** - 完全日本語インターフェース

## 🚀 使い方

### 基本操作

1. **カレンダーの表示**
   - ◀/▶ ボタンで月を移動
   - 「今日」ボタンで今月に戻る

2. **家族メンバーの管理**
   - 「+ メンバーを追加」ボタンでメンバーを追加
   - メンバーごとに好きな色を設定
   - メンバータグの×ボタンで削除

3. **予定の追加**
   - カレンダーの日付をクリック、または「+ 予定を追加」ボタン
   - タイトル、日付、時刻、メンバー、詳細を入力
   - 保存ボタンで追加

4. **予定の確認・編集**
   - カレンダー上の予定をクリックで詳細表示
   - 編集ボタンで内容を変更
   - 削除ボタンで予定を削除

## 🎨 カスタマイズ

### メンバーの初期設定

デフォルトでは以下のメンバーが登録されています：
- パパ（青色）
- ママ（赤色）
- 子ども（黄色）

これらは自由に変更・削除できます。

### 色の変更

メンバー追加時にカラーピッカーで好きな色を選択できます。

## 📝 データ保存

すべてのデータはブラウザのLocalStorageに保存されます。
- 予定データ: `familyEvents`
- メンバーデータ: `familyMembers`

## 🔧 開発情報

### ローカルで起動

```bash
# プロジェクトディレクトリに移動
cd /home/user/webapp

# 簡易HTTPサーバーで起動（Python 3）
python3 -m http.server 8000

# または Node.js の http-server
npx http-server -p 8000
```

ブラウザで `http://localhost:8000` にアクセス
